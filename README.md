# NoxCounts - Contador de Inscritos Estimado
* [Clique aqui para acessar o Site](https://noxcounts.github.io/)

 Quer Ver Quantos Inscritos Um Canal Do YouTube Tem? Com o Contador de Inscritos Estimado do NoxCounts Você Consegue Ver!
 
![description](https://noxcounts.github.io/imagens/background01.png)

Coloque O Id Do Canal Na Caixa De Texto, Exemplo: "UC-lHJZR3Gqxm24_Vd_AJ5Yw, UCX6OQ3DkcsbYNE6H8uQQuVA" E Clique Em "Trocar Canal"

Novas Atualizações Em Breve No Site! 🚀
